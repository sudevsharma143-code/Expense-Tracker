# Expense Tracker

A beginner-friendly menu-driven command-line Expense Tracker developed in C++.

## Features
- Add expenses
- List all expenses
- Calculate category-wise total
- Calculate overall total
- Validated user input
- Handles invalid input without crashing

## Concepts Used
- Variables and data types
- Structure
- Functions
- Vector collection
- Loops
- if/else
- switch-case
- Defensive input handling

## Build and Run

### Linux / macOS
```bash
g++ main.cpp -o expense_tracker
./expense_tracker
```

### Windows
```bash
g++ main.cpp -o expense_tracker.exe
expense_tracker.exe
```

## Menu
1. Add Expense
2. List Expenses
3. Category Total
4. Overall Total
5. Exit
